# Bulau Bau GmbH · Website

Website der Bulau Bau GmbH, Trockenbau und Akustikarbeiten aus Bersenbrück.

- Reines HTML, CSS und JavaScript, kein Build-Schritt
- Kontaktformular über `send.php` (braucht Webhosting mit PHP)
- Saubere Adressen ohne `.html` über `.htaccess` (Apache)
- Schriften lokal in `assets/fonts/`, keine externen Dienste

## Ansehen

`index.html` im Browser öffnen. Das Formular verschickt erst Nachrichten, wenn die Seite auf einem Server mit PHP liegt.
